# 💌 Love Letter for Rani - Letter Writing Day Special

A romantic, interactive love letter web page designed especially for **Rani** on **World Letter Writing Day** (September 1st).

---

## 🌟 Features

1. **Interactive Wax-Sealed Envelope**: Tap the seal stamped with `"R"` to break the seal and unfold the parchment letter.
2. **Parchment Love Letter**: Heartfelt, elegant love letter tailored for a long-distance relationship.
3. **Long-Distance Connection Banner**: Visual representation of two connected hearts across the miles.
4. **Built-in Romantic Ambient Melodies**: Custom Web Audio API synthesizer that plays gentle melodic chimes (zero external audio files needed!).
5. **Interactive "Open When..." Note Cards**: Tap to flip and reveal secret sweet messages for Rani.
6. **Virtual Hug & Kiss Generator**: Tap the button for an explosion of floating hearts and sparkles.
7. **Mobile-Friendly & Responsive**: Looks great on iPhone, Android, tablets, and desktop screens.

---

## 🚀 How to View It Locally

1. Double-click `index.html` in file explorer to open it in your default browser (Chrome, Edge, Firefox, Safari).
2. Or in PowerShell / Terminal:
   ```powershell
   Start-Process "C:\Users\Rahad\love-letter-for-rani\index.html"
   ```
